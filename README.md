# 数字集成电路物理设计与 OpenROAD 学习记录

## 1. 学习目标

- 了解数字集成电路设计的完整流程，理解前端设计与后端设计的区别。

- 学习 OpenROAD 及 OpenROAD-flow-scripts（ORFS）的基本使用方法。

- 在学习过程中持续记录知识笔记、实验结果、遇到的问题和阶段性总结。

### 阶段一：建立基础认知
了解数字 IC 设计流程、后端设计的任务、常见术语及各阶段的作用。

### 阶段二：学习必要的技术基础
根据实际需要补充数字电路、Verilog、Linux、Git、逻辑综合和时序分析知识。

### 阶段三：OpenROAD 实践
学习 OpenROAD 和 ORFS 的基本使用方法，尝试运行官方示例，理解布局布线流程及其输出结果。

根据导师的指导，进一步学习具体的物理设计流程、EDA 算法或工具开发，并开展针对性的实践。
